## Installation

Copy the `SREP_Config.cfg` to the root of that drive and use the existing `EFI/BOOT/BOOTX64.efi` loader.(https://github.com/hboyd2003/SmokelessRuntimeEFIPatcher#usage)
Boot from the SREP drive and check `Main`, `Advanced`, and `Exit`. To preview the menus, exit with `Exit Discarding Changes`.

SREP applies the menu patches in memory each time you start it. Use the BIOS save action to apply any settings you choose to change.
